# 🎉 Event & Community Platform

A full-stack MERN application for managing events, organizations, and community engagement.

## Tech Stack

- **Frontend:** React 18 + Vite + TypeScript + Tailwind CSS v4
- **Backend:** Node.js + Express + TypeScript
- **Database:** MongoDB + Mongoose
- **Auth:** JWT + bcryptjs
- **Storage:** Cloudinary
- **PDF:** PDFKit
- **AI:** Google Gemini API

## Getting Started

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- Cloudinary account
- Google Gemini API key

### Backend Setup
```bash
cd server
cp .env.example .env
# Fill in your environment variables
npm install
npm run dev
```

### Frontend Setup
```bash
cd client
npm install
npm run dev
```
